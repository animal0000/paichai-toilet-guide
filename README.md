# 2026 배양전 학생 화장실 이용 안내 (효창운동장)

배양전(배재-양정 정기전) 당일 배재중·고등학교 학생들이 안전하고 질서 있게 화장실을 이용할 수 있도록 제작된 원페이지 안내 웹 및 모션그래픽 비디오 저장소입니다.

## 📍 핵심 안내 사항
- **목적지**: 응원석 정면 맞은편 **B출입구 2층 화장실**
- **랜드마크**: 지붕 위 태양광 패널 아래 **[파란 박스]** 출입구 계단
- **이동 동선**: 배재 응원석 우측 계단으로 이동 ➔ 동측 외곽 트랙 통로(도보 2~3분) ➔ B출입구 진입 후 **【오른쪽 2층】** 화장실

## 📁 주요 산출물

- `motion_graphic.html`: 웹 브라우저 Canvas 기반 인터랙티브 모션그래픽 플레이어 (60fps)
